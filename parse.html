FAQ

Questions about Parse

What's the difference between Parse and Extract?

Parse turns a whole document into Markdown, JSON or HTML. Extract pulls the fields you define into structured data, with a citation and confidence for each value. Many teams run both.

When should I use LiteParse instead?

LiteParse runs on your machine with no API key and suits simple, text-heavy documents. Move to Parse for dense tables, charts, handwriting and scans.

How is Parse priced?

By credits per page, depending on the mode. Every account gets 10,000 free credits a month.

Can I run Parse in my own cloud?

Yes. Parse runs in our cloud (Global or EU), in your own VPC, or fully on-prem and air-gapped.

Is my data used to train models?

No. See the Trust center for how documents are stored and deleted.
