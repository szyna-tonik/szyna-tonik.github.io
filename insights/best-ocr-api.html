An OCR API turns a scanned page or photo into machine-readable text over HTTP. The hard part isn't the characters anymore; every API on this list reads clean print well. The differences are in what comes back with the text (plain lines, layout blocks, Markdown, typed fields, bounding boxes), how much you can run before paying, what a thousand pages costs, and whether there's a public benchmark behind the accuracy claim.

This guide compares eight OCR APIs on those four things: LlamaParse, Google Document AI, Azure AI Document Intelligence, Amazon Textract, Mistral OCR, ABBYY Vantage, Nanonets and OCR.space. Prices are US list as of November 13, 2026. Where an accuracy figure appears, we say whose benchmark it is.

Our pick is LlamaParse. It does OCR as the first step of agentic document processing: a layout model segments the page, the right model reads each region, and the result comes back as Markdown, JSON or text with bounding boxes, ready for extraction into typed fields. On ParseBench-2, the 4.3k-case public parsing benchmark LlamaIndex published on November 12, 2026, LlamaParse Agentic Plus scores 89.8, 5.9 points ahead of the next document parser, and the free plan's 10,000 credits a month cover 10,000 pages on the Fast tier.

How we chose these eight

We started from what developers ask when they search for an OCR API: which one handles complex documents, which has a free tier worth building on, which returns structured JSON, which holds up on high-volume financial paperwork, and which can run inside a private network. An API made the list if it reads scanned documents and images over a public HTTP interface with published pricing or a published free tier, and if it's one developers compare by name.

LlamaParse is a LlamaIndex product. Its figures come from the published pricing page and from ParseBench-2, LlamaIndex's public benchmark, which ranks 41 configurations from 18 document parsers, 14 vision models and 9 open-weight models. The other APIs' figures are their own published prices and claims, and we say so where one appears.

1. LlamaParse

ParseBench-2: 89.8 overall

LlamaParse is an OCR API in the sense that matters to a developer: you send a PDF, image or Office file and get text back over REST. What's different is what happens in between. A layout model segments the page, an orchestrator routes each region to the right OCR model, LLM or vision model, and validation checks the result before it's assembled into Markdown, JSON or plain text with bounding boxes. Tables survive as tables, reading order survives across columns, and charts come back as values, not pixels.

That's why it leads a public benchmark rather than a feature list. On ParseBench-2 (4.3k cases, six dimensions: text, formatting, tables, charts, forms and visual grounding), LlamaParse Agentic Plus scores 89.8 overall, Agentic 86.0 and Cost Effective 84.6. The next-best document parser is 5.9 points behind Agentic Plus, Mistral OCR 4.1 scores 72.5 and Azure Document Intelligence 66.1. On visual grounding, the dimension that decides whether you can show a user where a value came from, Agentic Plus scores 87.5 against a median of 64.5 for direct vision models.

What the API gives you

  • Four parsing tiers priced in credits per page: Fast at 1, Cost Effective at 3, Agentic at 10, Agentic Plus at 25. Pick per document type, or let the cost optimizer route only hard pages to the expensive tier.
  • The reading is done by OCRia-1, LlamaIndex's own document model, on the Cost Effective and Agentic tiers. Pin a dated version for production runs.
  • Markdown, JSON and plain-text output with page numbers and bounding boxes; natural-language parsing instructions for edge cases.
  • Extraction in the same pipeline: give it a schema and get typed fields with a confidence score and page citation on each, at 95.6% F1 on ExtractBench.
  • Async jobs with webhooks, batches of up to 10,000 files on Pro and Enterprise, files up to 10,000 pages, US and EU regions.

Best for

  • Scanned PDFs where layout carries meaning: financial statements, contracts, forms, technical manuals.
  • Teams that want OCR, parsing and field extraction from one API instead of three services.
  • Agents and automations that call parsing as a tool through the hosted MCP server.

Watch out for

  • It's priced in credits, not pages. Fast is 1 credit a page; Agentic Plus is 25. Budget by tier, not by the headline rate.
  • It's a hosted service. Running in your own cloud is an Enterprise plan.
  • ParseBench-2 is LlamaIndex's own benchmark. It's public and the cases are available, but run your own 50 pages before you trust the number.

Integration and cost

  • Integration: REST API; SDKs in Python, TypeScript, Go and Java; a CLI; webhooks; a hosted MCP server at mcp.llamaindex.ai for Cursor, VS Code, Claude Code and Codex.
  • Runs in your network: hosted, with US and EU regions; deployment in your own cloud is an Enterprise plan.
  • Data handling: SOC 2 Type II, HIPAA with a BAA, GDPR; files cached for 48 hours or not at all; no training on customer data.
  • Cost: pay as you go at $1.50 per 1,000 credits with 10,000 free credits a month, so Fast parsing works out to $1.50 per 1,000 pages and Agentic Plus to $37.50. Pro at $500 a month brings the rate to $1.25 per 1,000 credits. Details on the pricing page.

Here's the whole call in Python: upload the file, parse it on the Agentic tier, and read Markdown back page by page. Swap the tier for cost_effective on simpler pages, or agentic_plus for dense financial reports.

pip install "llama-cloud>=2.8"

from llama_cloud import LlamaCloud

client = LlamaCloud()  # reads LLAMA_CLOUD_API_KEY

file = client.files.create(file="./scanned-statement.pdf", purpose="parse")

result = client.parsing.parse(
    file_id=file.id,
    tier="agentic",        # fast | cost_effective | agentic | agentic_plus
    version="latest",
    output_options={"markdown": {"tables": {"output_tables_as_markdown": True}}},
    expand=["markdown", "items"],
)

for page in result.markdown.pages:
    print(page.markdown)   # Markdown per page, tables intact

2. Google Document AI

ParseBench-2: No public parsing benchmark result.

Google Document AI is the document side of Google Cloud's OCR offering; Cloud Vision's Text Detection is the image side. Enterprise Document OCR reads text from scans and PDFs at $1.50 per 1,000 pages with the first 1,000 a month free. Layout Parser adds blocks, tables and chunking for $10 per 1,000. Form Parser and Custom Extractor return key-value pairs and typed entities at $30 per 1,000, with Custom Extractor running on Gemini for schema-driven extraction.

It fits a team already on Google Cloud that wants OCR next to BigQuery and Vertex AI with regional processing and a managed evaluation console. The trade-off is that the job is split across processors with separate price lines, and the output is a JSON Document object you convert to Markdown yourself if an LLM is the consumer.

What the API gives you

  • Enterprise Document OCR: text, layout blocks and language detection; 200+ languages for printed text.
  • Layout Parser: blocks, tables and ready-made chunks; Form Parser: key-value pairs and checkboxes; Custom Extractor: your schema, with confidence per entity.
  • Batch processing from Cloud Storage; US and EU processing locations.

Best for

  • Google Cloud pipelines that OCR at volume and land results in BigQuery.
  • Teams that want zero-shot entity extraction on Gemini without leaving the platform.

Watch out for

  • OCR plus layout plus extraction is three processors and three bills: $1.50 + $10 + $30 per 1,000 pages.
  • No Markdown output from the OCR processor; Layout Parser gets closest.
  • Several Gemini-based processor versions are still preview, and some don't meet data-residency commitments.

Integration and cost

  • Integration: REST and gRPC with Python, Java, Node, Go and .NET client libraries; processors created per project and region.
  • Runs in your network: no. Document AI is cloud only, with US and EU processing locations.
  • Cost: Enterprise Document OCR $1.50 per 1,000 pages ($0.60 above five million), first 1,000 free; Layout Parser $10; Form Parser and Custom Extractor $30 ($20 above a million). Cloud Vision Text Detection is also $1.50 per 1,000 with 1,000 free.

3. Azure AI Document Intelligence

ParseBench-2: 66.1 overall

Azure AI Document Intelligence packages OCR as the Read model, layout analysis as the Layout model, and extraction as prebuilt and custom models, all behind one REST API. Read costs $1.50 per 1,000 pages and returns text with a per-line handwriting flag. Layout costs $10 and returns tables, selection marks, paragraphs and, in the v4.0 API, Markdown. Custom extraction models trained from five samples per class return typed fields at $30 per 1,000.

Two things set it apart in this group. The free F0 tier gives 500 pages a month on every model, not only OCR, and Read and Layout ship as Docker containers you can run inside your own network. On ParseBench-2 the Layout model scores 66.1 overall, so treat it as reliable text and tables rather than a parser for charts and complex formatting.

What the API gives you

  • Read for OCR, Layout for structure and Markdown, prebuilt models for invoices, receipts, IDs and tax forms, custom models for your own layouts.
  • Confidence and bounding polygons on every element; a document type and page ranges from the classifier.
  • Containers for Read and Layout; Document Intelligence Studio for labeling and testing.

Best for

  • Azure-centric teams that want OCR, layout and extraction under one procurement line.
  • Workloads that have to run disconnected or inside a private network.

Watch out for

  • The 66.1 ParseBench-2 score reflects weak chart and formatting handling; tables and text are fine.
  • Custom models need samples and a training run billed at $3 an hour; there's no zero-shot option.
  • Containers cover Read and Layout only; prebuilt and custom models stay in the cloud.

Integration and cost

  • Integration: REST API with Python, .NET, Java and JavaScript SDKs; data processed in the resource's region; Docker containers for Read and Layout.
  • Runs in your network: partly. Read and Layout ship as Docker containers; prebuilt and custom models stay in the cloud.
  • Cost: Read $1.50 per 1,000 pages; Layout and prebuilt models $10; custom extraction $30; custom classification $3; 500 pages a month free on F0 (East US retail list, November 13, 2026).

4. Amazon Textract

ParseBench-2: No public parsing benchmark result.

Amazon Textract is the AWS OCR API, and its model is features you add to a call. DetectDocumentText returns lines and words at $1.50 per 1,000 pages. AnalyzeDocument adds Tables ($15), Forms ($50), Queries ($15), Signatures ($3.50) and Layout (free with Tables), each priced per page and combinable in one request. Queries lets you ask "What is the invoice total?" in plain English and get the answer as its own block.

It's the path of least resistance when the documents already live in S3: synchronous calls for single pages, asynchronous jobs with SNS notifications for multi-page PDFs, IAM for access. The limits are the output, which is JSON blocks with geometry and no Markdown, and handwriting, which is English only.

What the API gives you

  • Text, tables, key-value pairs, query answers, signatures and layout blocks, all with confidence and bounding geometry.
  • AnalyzeExpense for invoices and receipts and AnalyzeID for identity documents as separate operations.
  • Custom Queries adapters to tune query answers on your own documents.

Best for

  • AWS-native pipelines with S3 triggers, Lambda and event-driven processing.
  • Forms and tables with stable layouts where key-value output is what you need.

Watch out for

  • Feature pricing stacks: Forms plus Queries plus Signatures on one page is $68.50 per 1,000 before text.
  • JSON blocks only; converting to Markdown for an LLM is your code.
  • The free tier lasts three months and covers 1,000 text pages but only 100 analysis pages a month.

Integration and cost

  • Integration: boto3 or any AWS SDK; StartDocumentAnalysis plus SNS for async; AWS regions only.
  • Runs in your network: no. AWS regions only.
  • Cost: Detect Document Text $1.50 per 1,000 pages ($0.60 above a million); Tables $15; Forms $50; Queries $15; Signatures $3.50; AnalyzeExpense $10 (US West list, November 13, 2026).

5. Mistral OCR

ParseBench-2: 72.5 overall

Mistral OCR is a single model behind one endpoint. Send a PDF, image or Office file and the current release, OCR 4.1, returns Markdown per page with tables, extracted images, paragraph-level bounding boxes and confidence scores, in a JSON envelope. Mistral prices it at $4 per 1,000 pages, or $2 through the batch API, and claims 170 languages and a 72% human-preference win rate against competing systems on 600 documents. Those are Mistral's figures.

On ParseBench-2, Mistral OCR 4.1 with annotation scores 72.5 overall, which places it above the cloud OCR models and below the agentic parsers. For a team that wants Markdown out of multilingual scans at a flat price with no processor matrix to learn, it's the simplest API on this list. Enterprise customers can also run it as a single self-hosted container.

What the API gives you

  • Markdown, tables (inline Markdown or HTML), images as base64, paragraph-level bounding boxes and confidence scores.
  • Document annotation on top of OCR for schema-style extraction, priced separately.
  • Batch inference at half price; a self-hosted container on enterprise plans.

Best for

  • Multilingual document OCR to Markdown at a predictable per-page price.
  • Teams that want one endpoint rather than a family of processors.

Watch out for

  • No published free tier for the OCR API; you pay from the first page.
  • The 72.5 ParseBench-2 score is 17 points behind the leader on charts, forms and grounding.
  • The OCR 4.0 model is deprecated as of September 2026; pin to OCR 4.1 or the latest alias.

Integration and cost

  • Integration: REST API and Python and TypeScript SDKs; document_url or image_url inputs; batch API; self-hosted container for enterprise.
  • Runs in your network: yes, as a self-hosted container on enterprise plans.
  • Cost: $4 per 1,000 pages; $2 per 1,000 in batch; document annotation extra (Mistral's published pricing, November 13, 2026).

6. ABBYY Vantage

ParseBench-2: No public parsing benchmark result.

ABBYY Vantage is the enterprise capture platform with an API in front of it. OCR, classification and extraction are packaged as skills: pretrained ones for invoices, receipts, IDs and other common documents, and custom ones trained in a low-code designer. Each result carries a probability score, low-confidence fields can route to a verification station, and reviewer corrections feed back into the model. It covers more than 200 languages and runs in ABBYY's cloud or on your own infrastructure.

It's the right call when OCR is the front of a mailroom or shared-services process that operations staff own, and when the deployment has to be on-premises. For a developer who wants to send a file and get text, it's a platform to adopt rather than an endpoint to call, and there's no published price.

What the API gives you

  • Skills that combine OCR, classification and extraction; output as JSON, CSV or XML.
  • Probability scores, human review stations and continuous learning from corrections.
  • Cloud or on-premises deployment; connectors for UiPath, Power Automate, Blue Prism and Automation Anywhere.

Best for

  • Digital mailroom, accounts payable and logistics documents at enterprise volume.
  • Organizations that need OCR inside their own data center with reviewers in the loop.

Watch out for

  • Quote-only pricing and no self-serve tier to test against.
  • Setup is a project: skills, connectors and review stations all need configuring.
  • No Markdown output and no public benchmark result to compare.

Integration and cost

  • Integration: REST API; RPA connectors; intake from email, folders, scanners and mobile.
  • Runs in your network: yes. Cloud or on-premises deployment.
  • Cost: quote only.

7. Nanonets

ParseBench-2: No public parsing benchmark result.

Nanonets wraps OCR in a workflow builder. You chain blocks: an extraction block reads a document into the fields you define, a classification block labels it, routing and export blocks send it on. Pricing is per block run rather than per page: $0.30 for an extraction or generative block, $0.10 for classification or validation, $0.02 for formatting, routing and export. The Starter plan is free with $50 in credits, then $100 a month.

It suits an operations team that wants OCR plus routing without engineering, and volumes where per-document pricing beats a platform license. For raw OCR at scale the per-run unit works against it: a six-block workflow on 100,000 documents a month is a real bill, and the output is fields, not Markdown.

What the API gives you

  • Extraction into defined fields, classification, validation and routing as chained blocks.
  • Email, cloud-storage and API intake on every plan; ERP and database connectors on Growth.
  • Prepaid credits shared across the team that don't expire.

Best for

  • Invoice, receipt and purchase-order workflows built in a visual editor.
  • Moderate volumes where $0.30 a document is cheaper than a license.

Watch out for

  • Per-run pricing is per document, not per page; compare carefully against per-page APIs.
  • Classification isn't on the free tier; Growth pricing is by quote.
  • Private cloud, on-prem, SSO, HIPAA and SOC 2 are Enterprise-plan features.

Integration and cost

  • Integration: REST API, email and cloud-storage intake, custom Python blocks, ERP connectors on Growth.
  • Runs in your network: private cloud or on-premises on the Enterprise plan.
  • Cost: $0.30 per extraction run; $0.10 per classification run; Starter free with $50 credits, then $100 a month; Growth and Enterprise by quote.

8. OCR.space

ParseBench-2: No public parsing benchmark result.

OCR.space is the free OCR API people find first, and for what it does it's honest. The free tier allows 25,000 requests a month at 500 a day per IP, with a 1 MB file limit and three pages per PDF. Engine 2 covers 33 languages; Engine 3 covers more than 200 with handwriting, tables returned as Markdown and checkbox detection, limited to 1,000 conversions a month on the free plan. Output is JSON with word positions, plus a searchable PDF if you ask for one.

The PRO plan is $30 a month for 300,000 requests at 5 MB, and PRO PDF is $60 for 100 MB files and long PDFs. It's a per-request service, not a per-page one, which suits receipts, screenshots and single-page images. It isn't built for 200-page scans, confidence-gated workflows or structured extraction.

What the API gives you

  • JSON text with word and line coordinates; optional searchable PDF.
  • Engine 3 with handwriting, Markdown tables and checkboxes; auto language detection.
  • No document storage: files are processed and the output link expires in an hour.

Best for

  • Prototypes, hobby projects and low-volume image OCR.
  • Single-page receipts and screenshots where a free key is the whole requirement.

Watch out for

  • 1 MB and three pages per request on the free plan; multi-page scans need PRO PDF.
  • No structured fields, no confidence routing, no benchmark result.
  • Free-tier searchable PDFs carry a watermark.

Integration and cost

  • Integration: REST (GET or POST) with an API key; client libraries from the community.
  • Runs in your network: yes. OCR.space Local is an installable version for your own servers, licensed through sales.
  • Cost: free for 25,000 requests a month; PRO $30 a month; PRO PDF $60; Enterprise from $999 (OCR.space's published pricing, November 13, 2026).

Choosing an OCR API for your stack

What's the best OCR API for complex documents?

Complex means the page has structure the text alone doesn't carry: multi-column reports, nested tables, charts, forms, footnotes that reference figures. The APIs that handle it are the ones that reconstruct layout before they emit text. LlamaParse leads ParseBench-2 on exactly those dimensions, with Agentic Plus at 89.8 overall and the top score on formatting, tables and charts. Mistral OCR 4.1 (72.5) is the next API on this list; the cloud OCR models (Azure Layout 66.1, with Google and Textract not ranked) are built for text and tables, not charts or reading order across columns. For handwritten forms specifically, see our guide to the best OCR for handwritten forms.

Which OCR APIs have a generous free tier?

Measured in pages you can process before paying: LlamaParse gives 10,000 credits a month, which is 10,000 pages on the Fast tier or 1,000 on Agentic, and it renews monthly. OCR.space allows 25,000 requests a month, but at 1 MB and three pages each. Google's Enterprise Document OCR and Cloud Vision each include 1,000 pages a month free. Azure's F0 tier gives 500 pages a month on every model.

Textract's free tier is 1,000 text pages a month, and only 100 analysis pages, for three months. Mistral publishes no free OCR tier; Nanonets gives $50 in credits once; ABBYY offers trials by request.

What's the best OCR API for high-volume financial document extraction?

For financial documents the test is table fidelity plus a confidence signal you can route on. LlamaParse returns typed fields with per-field confidence and page citations, scores 95.6% F1 on ExtractBench, and at Agentic pricing runs $15 per 1,000 pages on pay as you go. Textract's Tables and Queries features ($15 each per 1,000) are the AWS route for statements with stable layouts. Azure's prebuilt invoice and bank statement models and Google's Form Parser cover the common forms at $10 to $30 per 1,000.

At volume, batch APIs matter: LlamaParse takes 10,000-file batches, Mistral halves its price in batch, and Google and Textract both run async jobs from object storage.

Which OCR API returns structured JSON output?

All eight return JSON; the question is what's in it. Textract and Google return blocks and entities with geometry. Azure returns elements with confidence and polygons and, from Layout, Markdown. Mistral returns Markdown per page inside JSON with bounding boxes. OCR.space returns lines and words with coordinates. Nanonets and ABBYY return the fields you defined.

LlamaParse returns three shapes: Markdown or text for an LLM, a JSON document tree with page numbers and bounding boxes, and typed JSON matching your own schema with confidence and citations on every field. If "structured" means "matches my schema," that last one is the answer.

Final thoughts

The OCR API that wins a demo on a clean invoice isn't necessarily the one that survives a 300-page scanned annual report. What survives is an API that keeps the layout, tells you how confident it is and where each value came from, prices in a unit you can forecast, and publishes a benchmark you can rerun on your own pages.

LlamaParse is where we'd start: Markdown, JSON or fields from one API, the top ParseBench-2 score by 5.9 points, and 10,000 free credits a month to prove it on your documents. Google, Azure and Textract win inside their own clouds when you need text and tables at $1.50 per 1,000 pages. Mistral wins on multilingual Markdown at a flat price. ABBYY and Nanonets win when OCR is the front door of a workflow that operations staff own, and OCR.space wins when the whole requirement is a free key.

Then test it the only way that counts: 50 of your ugliest pages through each shortlisted API, scored on the values that matter to your application, with a note of how many came back with a confidence score you could route on.

Is there a free OCR API?

Yes, several, with different ceilings. LlamaParse's free plan is 10,000 credits a month, enough for 10,000 Fast-tier pages, with the same output as paid tiers. OCR.space is free for 25,000 requests a month with a 1 MB, three-page limit per request. Google Cloud Vision and Document AI OCR include 1,000 pages a month. If you need layout, tables or fields on the free tier, LlamaParse is the only one here that includes them.

If zero cost is the requirement and you can run it yourself, Tesseract and PaddleOCR are free and open source. They read clean printed text well. What you give up is layout reconstruction, tables, a confidence score you can route on, and anyone to call when a page fails. Our best OCR software guide covers both alongside the APIs on this page.

What's the difference between an OCR API and a document parsing API?

An OCR API returns the text on a page, usually with coordinates. A document parsing API returns the page's structure: headings, tables, reading order, figures, often as Markdown an LLM can use. Most of the APIs on this list do some of both; Google, Azure and Textract sell them as separate processors or features, while LlamaParse and Mistral return structured output from one call. If parsing is the main job, our guide to the best document parsing APIs goes deeper on that side.

Which OCR API is most accurate for documents?

On the only public benchmark that scores these APIs side by side on text, formatting, tables, charts, forms and grounding, LlamaParse Agentic Plus leads at 89.8, LlamaParse Agentic at 86.0 and Cost Effective at 84.6, with the next document parser 5.9 points back, Mistral OCR 4.1 at 72.5 and Azure Document Intelligence at 66.1 (ParseBench-2, November 12, 2026). On clean printed text every API here is in the high nineties; the benchmark gaps come from tables, charts and reading order. Run your own pages before you decide, and score values, not characters.

Can I use GPT, Gemini or Claude as an OCR API instead?

You can, and on ParseBench-2 the best direct vision model scores 85.7, below LlamaParse Agentic Plus and above most parsers. Two things count against it in production: cost, at about 6.5 cents a page for the top model against 2.8 cents for Agentic Plus, and grounding, where vision models score a median of 64.5 because they return text without reliable coordinates. A vision model is a fine prototype; an OCR API gives you bounding boxes, confidence and a stable schema.

Can an OCR API run inside my own network?

Some can. Azure ships Read and Layout as Docker containers. Mistral offers OCR as a self-hosted container on enterprise plans. ABBYY Vantage runs on-premises. LlamaParse runs in your own cloud on the Enterprise plan, with US and EU hosted regions otherwise. Google Document AI, Textract, Nanonets (outside Enterprise private cloud) and OCR.space are hosted only. If data can't leave the network and there's no enterprise budget, the open-weight models on ParseBench-2 (best score 77.1) are the self-hosted alternative.
